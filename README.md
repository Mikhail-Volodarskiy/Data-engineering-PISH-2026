# Инжиниринг данных

Проект содержит ETL-пайплайн для загрузки, валидации, преобразования и записи кредитного датасета в БД.

## Датасет

Для анализа данных был выбран датасет [Credit Risk Dataset](https://www.kaggle.com/datasets/rihabkaci99/credit-risk-dataset) с платформы Kaggle. Данные предназначены для построения модели классификации дефолта при выдаче кредита.

Датасет содержит 1000 наблюдений и 21 столбец (20 признаков и 1 таргет), включая категориальные и числовые переменные. В некоторых признаках встречаются значения `none` и `unknown`, которые требуют отдельной обработки на этапе подготовки данных.

Файл с исходными данными: [credit.csv](https://drive.google.com/drive/folders/1Uvd0gjNRxdypGUIJ6B4jJ_6P_5PfJDhk?usp=sharing) (156 КБ).

## ETL-пакет

Пакет расположен в директории:

```
src/etl/
```

### `extract.py`

Отвечает за экстракцию данных с Google Drive и сохранение локального CSV.

### `transform.py`

- приведение типов данных с помощью `pandas.convert_dtypes()`.
- сохранение подготовленного датасета в формате Parquet.

### `validation.py`

- `validation_raw()` проверяет исходный датасет.
- `validation_transformed()` проверяет преобразованный датасет.
- `validation_load()` проверяет результат загрузки в БД и сравнивает фактическое количество строк в таблице с ожидаемым.

### `load.py`

Отвечает за загрузку подготовленных данных в БД.

### `main.py`

Главная точка запуска ETL-пайплайна.

## Запуск ETL

ETL принимает обязательный параметр `--limit` от 1 до 100, определяющий количество строк для загрузки в базу данных.


Пример запуска:

```
uv run etl --limit 100
```

После успешного выполнения:

- исходный CSV сохраняется в `data/credit.csv`.
- преобразованный датасет сохраняется в `data/credit.parquet`.
- заданное количество строк загружается в БД.
- количество строк в итоговой таблице проверяется.
- в консоли выводится сообщение об успешном завершении ETL-пайплайна.
