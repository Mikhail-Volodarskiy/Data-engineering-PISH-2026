# Data-engineering-PISH-2026

Для анализа данных был выбран датасет ["Credit Risk Dataset"](https://www.kaggle.com/datasets/rihabkaci99/credit-risk-dataset) с kaggle.com, данные предназначены для построения модели классификации дефолта при выдачи кредита. В датасете 21 признак (категориальные и числовые) и 1000 строк. Среди признаков есть строки отмеченные none, unknown. На странице датасета отсутствую готовые EDA. Файл с сырыми данными [credit.csv](https://drive.google.com/drive/folders/1Uvd0gjNRxdypGUIJ6B4jJ_6P_5PfJDhk?usp=sharing)
