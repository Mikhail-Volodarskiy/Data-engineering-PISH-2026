# Инжиниринг данных

## Датасет

Для анализа данных был выбран датасет [Credit Risk Dataset](https://www.kaggle.com/datasets/rihabkaci99/credit-risk-dataset) с платформы Kaggle. Данные предназначены для построения модели классификации дефолта при выдаче кредита.

Датасет содержит 1000 наблюдений и 21 столбец (20 признаков и 1 таргет), включая категориальные и числовые переменные. В некоторых признаках встречаются значения `none` и `unknown`, которые требуют отдельной обработки на этапе подготовки данных.

На странице датасета отсутствует готовый разведочный анализ данных (EDA).

Файл с исходными данными: [credit.csv](https://drive.google.com/drive/folders/1Uvd0gjNRxdypGUIJ6B4jJ_6P_5PfJDhk?usp=sharing) (156 КБ).

## Установка окружения

Для развертывания окружения и установки зависимостей из pyproject.toml выполните:

```bash
uv sync
```

Команда создаст виртуальное окружение .venv и установит необходимые зависимости проекта.

## Загрузка и подготовка данных

Скрипт `scripts/data_loader.py` загружает исходный датасет из Google Drive, приводит столбцы к подходящим типам данных и сохраняет подготовленный датасет в формате Parquet.

Для запуска выполните:

```bash
uv run python scripts/data_loader.py
```

После выполнения файл `credit.parquet` сохраняется в директорию `data/`.

## Разведочный анализ данных

Разведочный анализ данных (EDA) выполнен в Jupyter Notebook.

С результатами анализа можно ознакомиться в файле:

`notebooks/EDA.ipynb`

## Запись таблицы в БД

### Чтение локальной SQLite

Для получения параметров подключения к удалённой PostgreSQL используется локальная база creds.db.

Скрипт `scripts/sqlite_read.py` подключается к SQLite через SQLAlchemy, получает структуру таблицы access и выполняет SQL-запрос. Учётные данные не выводятся.

Запуск:

`uv run python scripts/sqlite_read.py`

### Настройка подключения к PostgreSQL

Для подключения к удалённой базе используется файл .env в корневой директории проекта.

Необходимые переменные:

- DB_HOST=
- DB_PORT=
- DB_USER=
- DB_PASSWORD=
- DB_NAME=homeworks

Параметры подключения берутся из локальной sqlite базы creds.db

### Запустить запись:
Скрипт scripts/write_to_db.py записывает первые 100 строк подготовленного датасета в таблицу volodarskiymo базы homeworks.

Запуск:

`uv run python scripts/write_to_db.py`

После записи скрипт проверяет количество строк в таблице и выводит их количество.
Если таблица уже существует, повторная запись не выполняется из-за параметра `if_exists="fail"`.
